## 1. Install Node.js 20 (or higher)

Node.js is what runs the web app on your laptop.

🔗 **Download:** https://nodejs.org/

- Click the big **"LTS"** button (Long-Term Support version, currently v20.x or v22.x).
- Run the installer with all default options.
- After install, open your terminal:
  - **Windows:** Press `Win + R`, type `cmd`, hit Enter
  - **Mac:** Press `Cmd + Space`, type `terminal`, hit Enter
- Type:
  ```
  node --version
  ```
- ✅ You should see something like `v20.x.x` or higher.

> **If you see "command not found":** restart your terminal. If still not working, reinstall Node.js and make sure you tick "Add to PATH" during install (Windows only).

## 2. Install an AI Code Editor (Pick ONE)

You'll paste prompts into this editor's "Agent" panel, and watch it build the project. Pick **ONE** of these two:

🔗 **Download:** https://cursor.com/

- ✅ You're good to go.

## 3. Get a Free Groq API Key

Groq is the AI service that powers your app. It's free, it's fast, and it never asks for a credit card.

🔗 **Sign up:** https://console.groq.com/

**Steps:**

1. Go to https://console.groq.com/ and sign up with your email **or** sign in with Google or GitHub. (No credit card required.)
2. After you're logged in, go to https://console.groq.com/keys
3. Click the **"Create API Key"** button.
4. Give it a name like `resume-shapeshifter-workshop`.
5. Click **"Submit"**.
6. **Copy the key immediately.** It starts with `gsk_...` — copy the whole thing.
7. **Save it somewhere safe** — Notes app, password manager, a sticky note, anywhere. You'll paste it into your project on workshop day.

> ⚠️ **You can only see the full key ONCE.** If you close the window without copying, you'll have to create a new key. Don't lose it.

**Free tier limits (more than enough for the workshop):**
- 30 API requests per minute
- 14,400 requests per day
- Llama 3.3 70B model included

## 4. Prepare Your Sample Files (have them ready in a Notes window)

You'll paste these directly into the app during the workshop. Have them ready in advance.

### A. Your resume (or any resume)

- Copy your existing resume into a plain text format (just text — no formatting).
- If you don't have a resume yet, grab any sample resume online.
- Save it in your Notes app, ready to paste.

### B. A real job description

- Go to LinkedIn Jobs, Naukri, Indeed, or any job site.
- Pick a job that interests you.
- Copy the **full description** (responsibilities, requirements, skills, qualifications).
- Save it in your Notes app, ready to paste.

> 🎯 **Pro tip:** Pick a job that's a STRETCH for your resume — not a perfect match. That way the AI has more interesting work to do, and you'll see a bigger "before / after" wow moment.

## ❓ Quick FAQ

**Q: Can I use VS Code instead of Cursor?**
A: No — VS Code doesn't have an AI Agent that can paste-and-build like Cursor or Antigravity. Use one of those two.

**Q: Will I need to know how to code?**
A: No. You'll paste 3 prompts into the AI agent. It writes the code. You watch it work and then use the app.

**Q: Will this cost money?**
A: No. Everything is free — Node.js, the editor, Groq, the whole project. Forever.

**Q: What if my Node.js version is older than 20?**
A: Uninstall the old version first, then install the new LTS from nodejs.org.

**Q: I'm on a corporate / school laptop and can't install things.**
A: Try Cursor's installer first — it usually installs without admin rights. If that fails, please use a personal laptop for the workshop.

**Q: How long will the workshop take?**
A: Exactly 90 minutes. We start on time and end on time.
